# エアコンサイス（AIR CONCISE）企業サイト

音楽制作会社「エアコンサイス（AIR CONCISE）」のコーポレートサイトです。
「空気のように自然で、簡潔に心へ届く音」をコンセプトに、会社紹介・事業内容・制作実績などを1ページで紹介しています。

> ※ 掲載している会社情報・制作実績・メンバー・連絡先はすべて架空のものです。

## 概要

- **構成**: `index.html` 1ファイルのみ（HTML / CSS / JavaScript を内包）
- **ビルド不要**: 外部ライブラリやビルドツールは使用していません
- **レスポンシブ対応**: PC・タブレット・スマートフォンで表示を最適化
- **アクセシビリティ配慮**: OS の「視差効果を減らす」設定時はアニメーションを停止

### ページ構成

| セクション | 内容 |
| --- | --- |
| HERO | キャッチコピーと波形アニメーション |
| ABOUT | 会社紹介と実績数（カウントアップ表示） |
| SERVICE | 事業内容（楽曲制作／映像・ゲーム音楽／サウンドデザイン／レコーディング・MIX） |
| WORKS | 制作実績 |
| TEAM | メンバー紹介 |
| NEWS | お知らせ |
| CONTACT | 会社情報とお問い合わせフォーム |

> お問い合わせフォームはデモ用です。入力チェックのみ行い、実際には送信されません。

## ブラウザで表示する手順

### 方法1: ファイルを直接開く

1. エクスプローラーでこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

特定のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」からブラウザを選ぶか、ブラウザのウィンドウへ `index.html` をドラッグ＆ドロップしてください。

### 方法2: コマンドから開く

PowerShell でこのフォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 補足

- Web フォント（Google Fonts）を読み込むため、インターネットに接続した状態で開くと正しいフォントで表示されます。オフラインでも閲覧は可能です（代替フォントで表示されます）。
